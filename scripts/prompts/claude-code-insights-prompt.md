# Claude Code 心得 Prompt

## 任务目标

每日推送 Claude Code（或通用 AI 编程工具）的使用技巧、工作流优化和实战经验。

## 搜索方向

- Claude Code 官方更新和文档
- Anthropic Blog / Discord 社区
- AI 编程工具最佳实践
- Cursor / Copilot / Windsurf 对比
- 开发者社区讨论（Reddit, Hacker News）

## 搜索关键词

```
Claude Code tips tricks 2026
Claude Code update changelog
AI coding assistant workflow
Anthropic developer blog
```

## 内容结构

```markdown
> 今日 Claude Code/AI 编程心得

## 🆕 更新动态
- Claude Code 或相关工具的最新更新（如有）

## 💡 使用技巧
- 2-3 个实用技巧，每个带具体操作步骤
- 不是泛泛的"用 AI 写代码"，要有具体场景

## 🔧 工作流优化
- 如何更好地集成 AI 编程工具到日常工作
- Prompt 技巧、上下文管理、项目结构建议

## 📊 工具对比
- Claude Code vs Cursor vs Copilot 等（如有新变化）

## ⚠️ 常见坑
- 使用中遇到的坑和解决方案
```

## 质量标准

- 技巧必须具体可操作，不是"多提示几句"
- 如果没有新更新，侧重技巧和工作流
- 来源链接必须准确（官方文档优先）
- 诚实标注：如果某个技巧未经亲自验证，要说清楚

## 搜索限制

- web_search: ≤ 2 次
- web_fetch: ≤ 2 次
