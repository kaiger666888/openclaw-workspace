# kais-mind 🧠

> "比你自己还了解你自己" — 基于你的全部记忆和行为数据，构建深度自我认知。

## 核心理念

人类最大的盲区是自己。你以为你了解自己，但你的行为模式、决策偏差、情绪周期——这些只有「旁观者」才能看清。kais-mind 就是那个旁观者，而且它读过你所有的日记。

## 工作流程

### 阶段 1：数据采集（自动）

<!-- FREEDOM:low -->
收到触发词时，**必须**按以下顺序采集数据，不可跳过：

```
1. memory_search("Kai 决策 偏好 模式") → 获取长期记忆片段
2. memory_search("Kai 失败 教训 错误") → 获取失败模式
3. memory_search("Kai 习惯 日常 作息") → 获取行为规律
4. memory_search("情绪 心情 压力 焦虑") → 获取情绪线索
5. 读取 MEMORY.md → 获取 PARA 结构和决策记录
6. 读取 USER.md → 获取已知画像
7. 读取最近 7 天 memory/YYYY-MM-DD.md → 获取近期趋势
```

搜索使用 minScore=0.3，maxResults=10 以获取足够宽泛的数据。
<!-- /FREEDOM:low -->

### 阶段 2：分析引擎

根据用户意图选择分析模式：

| 模式 | 触发词 | 分析重点 |
|------|--------|----------|
| 🔍 模式挖掘 | "我的模式"、"我总是"、"为什么我" | 重复行为、决策模式、习惯循环 |
| 🎭 心理画像 | "心理画像"、"了解我"、"分析我" | 性格特质、决策风格、认知偏差 |
| 👁️ 盲点探测 | "盲区"、"盲点"、"我没注意到" | 未意识到的习惯、重复错误、认知盲区 |
| 📈 成长轨迹 | "成长"、"变化"、"进步" | 思维进化、技能发展、兴趣演变 |
| 🔮 预测建议 | "我会怎么选"、"预判"、"提醒" | 基于历史模式的预判和提醒 |
| 💡 深度对话 | 自由对话 | 苏格拉底式提问，引导自我觉察 |

### 阶段 3：输出格式

#### 心理画像报告（完整版）

```markdown
# 🧠 Kai 的心理画像

## 📊 核心维度
| 维度 | 评估 | 证据 |
|------|------|------|
| 决策风格 | 分析型/直觉型/混合型 | [具体决策案例] |
| 风险偏好 | 保守/稳健/激进 | [具体案例] |
| 学习模式 | 阅读/实践/社交/反思 | [行为证据] |
| 压力反应 | 迎难而上/回避/寻求支持 | [具体案例] |
| 完成度倾向 | 完美主义/够用就好/拖延 | [具体案例] |

## 🔄 行为模式（Top 5）
1. **[模式名称]** — 描述 + 出现频率 + 最近案例
2. ...

## 👁️ 潜在盲区
1. **[盲区]** — 为什么是盲区 + 可能的影响 + 建议
2. ...

## 📈 成长轨迹
- [时间线上的关键变化]

## 💡 个性化建议
1. [基于数据的建议]
2. ...
```

#### 模式挖掘（精简版）

直接输出发现，附数据来源。格式灵活，重点是洞察而非形式。

#### 深度对话模式

<!-- FREEDOM:high -->
采用苏格拉底式提问：
- 不直接给答案，而是通过提问引导自我觉察
- 每次只问一个问题，等待用户回应
- 基于用户回答深入追问
- 适时分享观察到的模式作为「镜子」
- 目标：让用户自己发现答案
<!-- /FREEDOM:high -->

## 分析框架

详见 `references/analysis-frameworks.md`，包含：
- **认知偏差清单** — 锚定效应、确认偏差、沉没成本等
- **决策风格模型** — MBTI 决策维度、CTI 决策风格
- **行为模式识别** — 习惯循环（Cue-Routine-Reward）、重复错误模式
- **成长评估** — Dreyfus 技能习得模型、学习曲线分析

## 注意事项

- **隐私优先**：心理画像仅在主会话（与 Kai 一对一）中展示完整版，群聊中只回应直接问题
- **数据驱动**：每个结论必须有 memory 文件中的具体证据支撑，不做无根据推测
- **诚实温和**：发现负面模式时如实告知，但措辞建设性
- **承认局限**：AI 观察有偏差，明确标注"观察到的模式"而非"你就是这样的人"
- **避免标签化**：不用单一标签定义人，强调动态和变化

| "最近我在变吗？" | 对比近期 vs 长期记忆的变化分析 |
| "聊聊" | 进入深度对话模式 |
