# 投资大师思想精华 Prompt

## 任务目标

每日推送投资大师的经典思想和实战智慧，帮助建立长期投资思维。

## 人物轮换（按星期）

- **周一**：沃伦·巴菲特（致股东信、股东大会观点）
- **周二**：查理·芒格（多元思维模型、反向思考）
- **周三**：霍华德·马克斯（周期思维、风险控制）
- **周四**：彼得·林奇 / 菲利普·费雪（成长投资）
- **周五**：纳瓦尔·拉维坎特 / 瑞·达利欧（原则、杠杆）
- **周六**：乔治·索罗斯 / 塞思·卡拉曼（反身性、安全边际）
- **周日**：综合（多位大师观点对比/跨领域应用）

## 搜索关键词

```
[人物名] investment philosophy latest
[人物名] quotes wisdom
[人物名] letter to shareholders 2026
投资大师思想 [人物名]
```

## 内容结构

```markdown
> 今日大师：[人物名] — [核心思想一句话]

## 👤 大师简介
- 一段话介绍人物和投资风格

## 🧠 核心思想（2-3 条）
### 1. [思想标题]
- **原文/原话**（如有可能）
- **解读**：用通俗语言解释
- **应用**：如何应用到实际投资决策中

## 📖 案例分析
- 一个该大师的经典投资案例
- 来源链接

## ⚡ 今日启示
- 将大师思想转化为可执行的投资原则
- 与当前市场环境的关联

## 🔗 延伸阅读
- 推荐书籍/文章/演讲链接
```

## 质量标准

- 原话/原文引用必须准确，不能编造
- 解读要有深度，不能只是翻译
- 案例要有具体数据和来源
- "今日启示"要和当前市场有联系，不能空谈
- 至少 1 个外部来源链接

## 搜索限制

- web_search: ≤ 2 次
- web_fetch: ≤ 2 次
