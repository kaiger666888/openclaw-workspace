### 修复的基础设施问题（Claude Code 在高配机 tmux 完成）
1. **容器名冲突** — `_cleanup_containers` 用 `docker ps -q` 改为 `docker ps -aq`，停止的容器也清理；启动前按 name 直接 `docker rm -f`
2. **systemd watchdog** — `WatchdogSec=1min` 但守护进程没有 `sd_notify`，Worker 每 ~70s 被杀。改为 `WatchdogSec=0`
3. **VRAM drain** — 从固定 512MB 阈值改为基于基线（`baseline + 100MB`），桌面环境占 1.3GB 不再误报
4. **僵尸容器清理** — label-agnostic cleanup，解决旧 Worker 残留容器问题
5. **Woosh 启动阻塞** — 模型预加载移到后台线程，uvicorn 立即启动
6. **TTS 错误捕获** — `raise_for_status()` 改为显式状态码检查
7. **HF_HUB_OFFLINE** — 从源码移到 `extra_docker_args`，不需要改源码或重建镜像
