# VibeCoding 每日总结 Prompt

## 任务目标

每日推送 VibeCoding（氛围编程）相关的技巧、工具和灵感，鼓励动手实践和快速原型开发。

## 搜索方向

- Cursor / Windsurf / Claude Code / Copilot 等 AI 编程工具最新动态
- 有趣的 side project 灵感和教程
- 快速原型开发技巧（MVP、no-code、low-code）
- 开发者社区热帖（Reddit r/programming, Hacker News）
- 实用代码片段和自动化脚本

## 搜索关键词

```
AI coding tools 2026
vibe coding side project
Cursor IDE tips
Claude Code workflow
rapid prototyping AI
```

## 内容结构

```markdown
> 今日 VibeCoding 灵感

## 🔥 工具动态
- 工具更新/新功能（每条带来源链接）

## 💡 技巧分享
- 实用编程技巧或工作流优化

## 🎯 项目灵感
- 1-2 个值得做的 side project 灵感
- 技术栈建议

## 📦 资源推荐
- 教程/文档/开源项目链接
```

## 质量标准

- 每条信息带来源链接
- 侧重实用性和动手价值
- 避免纯理论，要有可操作的建议
- 至少 3 个不同的信息来源

## 搜索限制

- web_search: ≤ 2 次
- web_fetch: ≤ 3 次（降级时）
