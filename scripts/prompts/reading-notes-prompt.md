# 读书笔记 Prompt

## 任务目标

每日推送 2-3 篇高质量深度文章/论文的阅读笔记，涵盖技术、商业、思维成长等领域。

## 搜索方向

- Hacker News 首页热帖
- 知名博客（Paul Graham, Dan Abramov, Martin Fowler 等）
- Medium / Substack 热门长文
- arXiv 热门 AI 论文
- 国内外技术/商业深度报道

## 搜索关键词

```
site:news.ycombinator.com top stories today
best long reads technology 2026
deep dive article AI programming
Substack popular posts
```

## 内容结构

```markdown
> 今日深度阅读推荐

## 📖 文章 1：[标题]
- **来源**：[来源名](URL)
- **核心观点**（3-5 条要点）
- **为什么值得读**：一句话推荐理由
- **关键引用**：最有冲击力的一句话

## 📖 文章 2：[标题]
- （同上结构）

## 📖 文章 3：[标题]（可选）
- （同上结构）

## 🎯 延伸阅读
- 相关文章/书籍推荐链接
```

## 质量标准

- 每篇文章必须有来源链接
- 核心观点要提炼到位，不是复制摘要
- 优先选择有实际洞察的文章，而非资讯
- "为什么值得读"要有个人判断，不能泛泛而谈
- 涵盖不同领域（不要全是 AI）

## 搜索限制

- web_search: ≤ 2 次
- web_fetch: ≤ 4 次（需要抓取文章原文提取要点）
