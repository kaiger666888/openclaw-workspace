# kais-movie-gate - AIGC 视频质量门控系统

基于「提升AIGC短视频完播率策略体系」构建的质量预判门控，确保每条内容发布前达到可配置的质量标准。

## 核心原则

- **质量优先**：宁可多发一版打磨，不发一条不及格
- **数据驱动**：每个评分维度都有行业数据支撑
- **可配置**：阈值和权重均可调整，适应不同内容类型和平台
- **建设性**：不通过时给出具体改进建议，而非简单拒绝

## 门控流程

```
输入素材 → 6维度评分 → 加权总分 → 对比阈值 → 放行/驳回+改进建议
```

## 评分维度（6维度，满分100）

### 维度1：黄金3秒钩子（权重25分）

评估视频开头是否能抓住注意力。72%用户在3秒内决定去留。

**评分项：**
- ✅ 是否有明确的注意力锚点（悬念/痛点/反差/情绪/价值）
- ✅ 钩子类型与内容类型的匹配度
- ✅ 是否避免"片头动画+自我介绍+背景铺垫"（零延迟原则）
- ✅ 前3秒是否有视觉冲击（运动/色彩突变/表情夸张）

**扣分项：**
- ❌ 开头平淡，无明确钩子 → -8~10分
- ❌ 钩子与内容不匹配（标题党）→ -5~8分
- ❌ 有片头logo/自我介绍等冗余 → -3~5分

**判定参考：**
| 钩子类型 | 适用场景 | 有效性 |
|---------|---------|--------|
| 悬念钩子 | 知识类、故事类 | ⭐⭐⭐⭐⭐ |
| 痛点钩子 | 教程类、测评类 | ⭐⭐⭐⭐⭐ |
| 反差钩子 | 观点类、对比类 | ⭐⭐⭐⭐ |
| 情绪钩子 | 故事类、短剧 | ⭐⭐⭐⭐⭐ |
| 价值钩子 | 干货类、教程类 | ⭐⭐⭐⭐ |

### 维度2：内容结构与节奏（权重20分）

评估视频的叙事节奏和信息密度。

**评分项：**
- ✅ 是否遵循"心跳曲线"（每20-30秒有小高潮）
- ✅ 信息密度是否动态变化（非平铺直叙）
- ✅ 是否剔除了无关场景和冗余内容
- ✅ 结尾是否"高潮收尾"（避免"谢谢观看"式结尾）

**扣分项：**
- ❌ 节奏平淡，无起伏 → -6~10分
- ❌ 存在明显冗余段落 → -4~6分
- ❌ 结尾拖沓或无收束 → -3~5分

### 维度3：AIGC真实感（权重20分）

评估AI生成内容的真实感和去广告化程度。未优化的AIGC完播率不足15%。

**评分项：**
- ✅ 是否避免"过度精致化"（完美光线、完美构图、完美皮肤）
- ✅ 是否模拟"真人随手拍"风格（轻微抖动、自然光线）
- ✅ 语言是否自然（口语化、有语气词、避免书面腔）
- ✅ 情感表达是否到位（微表情、眼神流转、肢体语言）

**扣分项：**
- ❌ 明显AI痕迹（塑料感、游戏动画感）→ -8~12分
- ❌ 广告感强（过度精致的画面、商业腔调）→ -6~10分
- ❌ 恐怖谷效应（表情僵硬、眼神空洞）→ -8~12分
- ❌ 语言生硬书面化 → -3~5分

**真实感评分参考：**
| 表现 | 评分范围 |
|------|---------|
| 几乎无法区分AI与真人 | 18-20 |
| 有轻微AI痕迹但不影响观感 | 14-17 |
| 明显AI特征但内容有趣 | 10-13 |
| 强烈AI感+广告感 | 0-9 |

### 维度4：标题与封面（权重15分）

评估点击转化潜力。抖音搜索流量占31%，但仅12%创作者优化了关键词。

**评分项：**
- ✅ 标题是否有悬念+利益点的平衡
- ✅ 标题是否包含数字/疑问/冲突元素（不超过2种）
- ✅ 封面是否有高冲击力（高对比度、明确主体、情绪指向）
- ✅ 标题-封面-内容三者是否一致（非标题党）

**扣分项：**
- ❌ 标题平淡无吸引力 → -5~8分
- ❌ 标题党（标题承诺>30%未兑现）→ -8~12分
- ❌ 封面模糊/无主体/无情绪 → -4~6分
- ❌ 标题与内容严重不符 → -10~15分

### 维度5：时长适配（权重10分）

评估视频时长是否符合平台和内容类型的最佳区间。

**最佳时长参考：**
| 内容类型 | 最佳时长 | 完播率峰值区间 |
|---------|---------|--------------|
| 短剧 | 30-90秒/集 | 45-60秒 |
| 知识/教程 | 30-60秒 | 30-45秒 |
| 娱乐/搞笑 | 15-30秒 | 15-25秒 |
| 广告/带货 | 15-30秒 | 15-20秒 |
| 情感/故事 | 30-90秒 | 45-75秒 |

**扣分项：**
- ❌ 时长超出最佳区间2倍以上 → -5~8分
- ❌ 内容被拖长填充 → -3~5分

### 维度6：互动潜力（权重10分）

评估内容引发互动（点赞/评论/收藏/转发）的能力。

**评分项：**
- ✅ 是否设置互动引导点（提问、投票、争议观点）
- ✅ 是否有收藏价值（干货、清单、工具推荐）
- ✅ 是否有转发动机（社交货币、身份认同、情感共鸣）
- ✅ 是否有评论引导（开放性问题、争议话题）

**扣分项：**
- ❌ 无任何互动设计 → -4~6分
- ❌ 内容封闭无讨论空间 → -2~4分

## 评分配置

### 默认阈值

```yaml
# config.yaml（存储在 references/gate-config.yaml）
threshold:
  total: 65          # 总分低于此值不放行
  critical: 40       # 任何单维度低于此值一票否决
  warning: 75        # 总分在此区间给出警告但放行
  
dimensions:
  hook: 25           # 黄金3秒
  structure: 20      # 内容结构
  realism: 20        # AIGC真实感
  title_cover: 15    # 标题封面
  duration: 10       # 时长适配
  engagement: 10     # 互动潜力

platform_presets:
  douyin:
    total: 65
    duration_optimal: [15, 60]
  bilibili:
    total: 60
    duration_optimal: [30, 180]
  xiaohongshu:
    total: 60
    duration_optimal: [15, 90]
  youtube_shorts:
    total: 60
    duration_optimal: [15, 60]
```

用户可通过传入参数覆盖默认阈值：
- `--threshold 70` — 设置总分阈值
- `--platform douyin` — 使用平台预设
- `--type 短剧` — 使用内容类型预设

## 执行流程

### Step 1: 素材收集

根据输入类型收集素材：

**输入类型：**
| 类型 | 说明 | 处理方式 |
|------|------|---------|
| 脚本文本 | 分镜脚本/拍摄脚本/文案 | 直接分析文本 |
| 图片素材 | 封面/场景图/角色设定 | 用 `image` 工具分析 |
| 视频素材 | 已生成的视频片段 | 用 `video-frames` 提取关键帧后分析 |
| 完整作品 | 所有素材齐全 | 全维度分析 |

### Step 2: 多维度评分

对每个维度逐一评分，记录具体扣分原因。

**文本分析**（脚本/文案）：
- 直接分析钩子设计、结构节奏、语言自然度、互动引导
- 检查时长与内容密度的匹配

**图片分析**（封面/场景图）：
- 用 `image` 工具评估视觉冲击力、真实感、情绪传递
- 检查是否存在明显AI痕迹

**视频分析**（已生成视频）：
- 用 `video-frames` 提取关键帧（开头、中间、结尾各1帧）
- 分析视觉节奏变化、真实感表现

### Step 3: 生成评分报告

输出格式：

```
🎬 kais-movie-gate 质量门控报告

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 总分: XX/100  🟢放行 / 🔴驳回 / ⚠️警告
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

维度评分:
  🪝 黄金3秒钩子:   XX/25  ✅/⚠️/❌
  🎼 内容结构节奏:   XX/20  ✅/⚠️/❌
  🎭 AIGC真实感:     XX/20  ✅/⚠️/❌
  🖼️ 标题与封面:     XX/15  ✅/⚠️/❌
  ⏱️ 时长适配:       XX/10  ✅/⚠️/❌
  💬 互动潜力:       XX/10  ✅/⚠️/❌

❌ 扣分项:
  1. [维度] 具体问题描述 (-X分)
  2. [维度] 具体问题描述 (-X分)

✅ 亮点:
  1. [维度] 具体优点描述
  2. [维度] 具体优点描述

🔧 改进建议（按优先级排序）:
  1. [最关键的改进]
  2. [次要改进]
  3. [可选改进]
```

### Step 4: 门控决策

| 总分 | 决策 |
|------|------|
| ≥ 75 | 🟢 **放行** — 可以发布 |
| 65-74 | ⚠️ **警告放行** — 可以发布，但建议优化后重新检查 |
| < 65 | 🔴 **驳回** — 需要修改后重新提交 |
| 任一维度 < 40 | 🚫 **一票否决** — 该维度存在致命问题 |

驳回时必须给出：
1. 具体扣分原因（精确到哪一帧/哪一句）
2. 改进建议（参考 Notion 策略体系中的对应方案）
3. 改进后可重新提交检查

3. 内容结构与节奏控制

## 使用示例

### 基础用法
```
用户: 帮我做个质量门控检查
```
→ 分析当前作品素材，输出评分报告

### 指定素材
```
用户: 审核这个脚本 [粘贴脚本]
```
→ 基于文本进行评分

### 指定阈值
```
用户: 以70分为门槛检查这个视频 [视频路径]
```
→ 使用自定义阈值评分

### 只检查某个维度
```
用户: 检查这个封面的吸引力 [图片路径]
```
→ 只评估标题与封面维度

## 配置文件

门控配置存储在 `references/gate-config.yaml`，支持：
- 全局默认阈值
- 平台预设（抖音/B站/小红书/YouTube Shorts）
- 内容类型预设（短剧/知识/娱乐/广告）
- 自定义维度权重

## 集成点

- **kais-movie-agent**: 在视频管线中，拍摄完成后、发布前自动触发门控检查
- **kais-shooting-script**: 生成拍摄脚本时，可前置调用门控评估脚本质量
- **kais-xiaohongshu**: 发布前最后一道质量关卡
