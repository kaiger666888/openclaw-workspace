# 灵魂雷达 · Soul Radar

## 概述

灵魂雷达是一个**自下而上的社会结构性叙事挖掘工具**。它从公开数据中提取"结构性悲剧"——那些不是个人选择、而是社会力量驱动的不可逆转的冲突——将其结构化为**故事核 (Story Kernel)**，供影视/文学创作使用。

核心方法论：**六层地层学**——将社会分为制度(L1)、技术(L2)、人口(L3)、空间(L4)、代际契约(L5)、心灵(L6) 六个地层，逐层扫描结构性裂缝，多层叠加时产生最具震撼力的叙事共振。L6 心灵地层是 L1-L5 外部力量作用后的"内心沉积"——当外部结构性力量与内在心理崩塌同时呈现时，叙事冲击力最强。

理论基础：Bourdieu 场域理论 + Giddens 结构化理论 + Barthes 叙事结构分析。

## 触发场景

- 当用户说"灵魂雷达"、"soul-radar"、"社会裂缝"、"故事核"、"地层分析"、"叙实挖掘"、"结构性悲剧"
- 当用户说"挖故事"、"找选题"、"创作素材"、"时代痛点"、"现实矛盾"
- 当用户需要为影视/文学创作寻找**现实主义题材**
- 当用户想了解某个社会议题的**结构性根源**而非表面现象
- 当用户指定"分析 L1/L2/L3/L4/L5/L6"或"叠加分析"

## 六层地层速查

| 层级 | 名称 | 核心问题 | 典型数据源 |
|------|------|----------|-----------|
| L1 | 制度地层 | 谁被规训？谁被豁免？ | 政策文件、法律法规、裁判文书 |
| L2 | 技术地层 | 谁被替代？谁被增强？ | WEF就业报告、自动化研究 |
| L3 | 人口地层 | 谁在消失？谁在涌入？ | 人口普查、流动数据 |
| L4 | 空间地层 | 谁拥有空间？谁被挤出？ | 房价数据、城镇化报告 |
| L5 | 代际契约地层 | 父辈的语法在子辈世界还成立吗？ | 消费报告、资产负债调查 |
| L6 | 心灵地层 | 人的内在世界正在发生什么结构性坍缩？ | 心理健康白皮书、社会心态调查、信任度报告 |

> 详细说明见 [references/strata-guide.md](references/strata-guide.md)

## 使用流程

<!-- AUTO:自动化区 - 数据收集与初步分析全自动 -->
### 步骤 1：确定分析模式

根据用户输入确定分析模式：

- **单层分析**：用户指定了具体地层（如"L1 制度地层"、"分析技术替代"）
- **多层叠加分析**：用户说"叠加"、"共振"、"综合分析"，或未指定地层
- **每日扫描**：通过 cron 定时触发，推送 Top N 故事核

若用户指定了主题（如"外卖骑手"、"AI替代"），将其作为搜索关键词补充。

### 步骤 2：数据采集

<!-- AUTO:自动化区 -->
运行分析脚本生成搜索关键词：

```bash
python3 scripts/analyze.py --stratum <L1-L6> [--topic "主题词"]
```

脚本输出：
- 该地层推荐的搜索关键词列表
- 对应的 prompt 模板路径
- 分析指令（结构化 prompt 供 agent 执行）

然后使用 **kais-search skill** 搜索 3-5 个关键词，获取最新公开数据。

**搜索策略**（按优先级）：
1. **kais-search**：16 引擎聚合（国内7 + 国际9），中文查询自动优先国内引擎（百度/ Bing CN / 360 / 搜狗 / 微信 / 神马），无 API 限制
2. **web_search**（Brave API）：作为补充，注意 429 限流（每分钟 1 次）
3. **multi-search-engine**：如果 kais-search 不可用，独立降级（Brave → Exa → 秘塔 → Jina → Bing CN）

**各层搜索平台建议**：
| 地层 | 推荐引擎 | 搜索关键词方向 |
|------|---------|--------------|
| L1 | 微信搜一搜、百度 | 政策文件名 + "解读/影响/争议" |
| L2 | Google、Bing INT | 英文报告关键词（"future of jobs""automation impact"） |
| L3 | 国家统计局官网、百度 | "人口普查" + "老龄化/少子化/流动" + 年份 |
| L4 | 贝壳研究院、百度 | "房价" + "住房/租房/城镇化" + 数据 |
| L5 | 小红书、知乎、百度 | "代际消费" + "年轻人 父母" + "囤积/断舍离" |
| L6 | 百度学术、知乎、微博 | "心理健康 报告" + "孤独 调查" + "年轻人 意义感" |

### 步骤 3：地层分析

<!-- AUGMENT:增强区 - AI生成故事核，人做最终判断 -->
读取 `prompts/stratum-analysis.txt`，将搜索结果填入 prompt，执行 LLM 分析。

输出必须符合 `schemas/story_kernel.json` 定义的 JSON Schema。

**分析要点**：
- 每个故事核必须附带**可验证的数据来源**
- "不可言说性"(unspeakability) 评分：0-10 分，越高表示该冲突越难在公共空间公开讨论
- 寻找**结构性公式**：不是"某人做了某事"，而是"某结构力量迫使某类人走向某结局"

### 步骤 3.5：深度分析模式（可选）

<!-- AUGMENT:增强区 -->
当用户说"深度分析"、"深度挖掘"、"deep"，或单次搜索结果不够深入时，启动 **deep-research skill** 对指定地层做多轮深度研究。

**使用方式**：
```
启动 deep-research，参数：
- 主题：[地层名] + [具体方向，如"灵活就业社保断裂"]
- 搜索轮次：3
- 思考深度：deep
- 聚焦维度：数据验证、反例搜索、历史对比
```

deep-research 会自动执行 3 轮搜索迭代，生成带引用的结构化报告。将报告作为输入数据填入步骤 3 的分析 prompt。

**适用场景**：
- 需要跨语言数据（中英文交叉验证）
- 需要历史纵向对比（如"10年人口变化趋势"）
- 需要学术论文支撑（deep-research 会搜索 arXiv 等）

### 步骤 4：多层叠加（可选）

<!-- AUGMENT:增强区 -->
若为叠加模式，读取 `prompts/stratified-merge.txt`，将 2-3 个地层的分析结果交叉分析。

核心目标：寻找**结构性力量的共振点**——当多层力量同时作用于同一群人时，产生的故事核最具冲击力。

示例：L1(灵活就业政策) + L2(AI替代) + L4(高房租) → 三重夹击下的城市青年

### 步骤 5：格式化输出

<!-- AUTO:自动化区 -->
将分析结果格式化为可读报告，包含：

```
🔍 灵魂雷达 · [地层名] 分析报告

📊 结构性公式
[一句话描述结构性矛盾]

👤 微观裂隙
[典型人物] 在 [具体场景] 中面对 [冲突]

💡 叙事角度
1. [角度名]: [驱动故事的核心问题]
2. [角度名]: [驱动故事的核心问题]

📐 不可言说性: X/10
📝 数据来源: [可验证的公开数据引用]
```

若为叠加分析，额外输出"地层共振图"——展示多层力量如何交汇。

### 步骤 6：每日扫描模式

<!-- AUTO:自动化区 -->
通过 cron 触发时，读取 `prompts/daily-scan.txt`，对六层地层各搜索 2-3 个关键词（使用 **kais-search**），筛选 Top 3 故事核推送到 Telegram。

**推荐 cron 配置**：
- 频率：每日 06:00（早高峰前推送，供一天创作参考）
- 模式：叠加分析（默认 L1+L3+L6 三层共振）
- sub-agent 执行，避免阻塞主会话

筛选标准：
- 不可言说性 ≥ 6
- 有明确数据支撑
- 叙事角度新颖（避免常见套路）

## Story Kernel 输出格式

每个故事核必须包含以下字段（完整 Schema 见 `schemas/story_kernel.json`）：

| 字段 | 说明 |
|------|------|
| `stratum` | 所属地层 (L1-L6) |
| `tectonic_forces` | 结构性力量列表 |
| `macro_fissure` | 宏观裂缝：数据引用 + 结构性公式 |
| `micro_fissure` | 微观裂隙：典型人物 + 场景 + 冲突 |
| `narrative_angles` | 叙事角度列表（至少 2 个） |
| `consumption_grammar_clash` | 代际消费语法冲突（L5 必填，其他可选） |
| `psychic_landscape` | 心灵景观（L6 必填，其他可选） |
| `unspeakability` | 不可言说性评分 (0-10) |
| `verifiability` | 可验证性：public_data 或 derived_inference |

## 伦理约束

- **只使用公开数据**：不侵入私人账户，不使用非公开数据集
- **可验证性优先**：每个故事核必须附带公开数据来源，不编造数据
- **反刻板印象**：分析时主动寻找反例，避免强化群体偏见
- **无知之幕**：分析不预设用户身份、政治立场或创作意图
- **语义漂白**：输出中任何涉及具体个案的信息必须去标识化，不可还原为个人身份

## 注意事项

- L1-L6 是分析框架，不是价值判断；每层都有叙事价值
- "不可言说性"高分不等于"应该回避"，而是"有叙事张力"
- 多层叠加分析比单层分析耗时更长（需要逐层分析后再合并）
- 数据源更新频率不同：L1/L2 较快（月级），L3/L4 较慢（年级）
- 故事核是创作素材，不是新闻报道；它提取的是结构性模式，不是具体事件
- **L6 心灵地层的特殊性**：L6 不是独立的外部结构力量，而是 L1-L5 作用后的"内心沉积"。单层 L6 分析也有价值（如心理健康白皮书直接揭示的集体心理症状），但 L6 的最强叙事效果来自于与其他地层的叠加——外部结构性力量 + 内在心理崩塌的双重夹击，是现实主义叙事中最具穿透力的视角
