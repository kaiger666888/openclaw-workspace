# 剧本分析 Prompt 模板

> 用于 LLM 解析和分析剧本的结构化提示词

## Prompt 1: 剧本结构化解析

将纯文本剧本解析为结构化JSON，供后续分析使用。

```
你是一个专业的剧本分析师。请将以下剧本解析为结构化JSON格式。

要求：
1. 识别每个场景（通过场景标题、时间/地点变化判断）
2. 提取每个场景中的角色
3. 统计对话行数
4. 评估动作描写密度（0-1）
5. 识别情绪关键词（从以下分类中选择：愤怒、恐惧、悲伤、厌恶、惊讶、期待、信任、喜悦）
6. 评估场景冲突强度（1-10）
7. 估算场景时长（秒）

输出JSON格式：
{
  "title": "剧本标题",
  "genre": "类型",
  "total_scenes": N,
  "scenes": [
    {
      "index": 1,
      "location": "地点",
      "time": "时间",
      "characters": ["角色A", "角色B"],
      "dialogue_count": N,
      "action_density": 0.X,
      "emotion_words": ["情绪1", "情绪2"],
      "conflict_level": N,
      "duration_estimate": N,
      "plot_point_type": "none|inciting|midpoint|climax|resolution",
      "summary": "一句话描述"
    }
  ],
  "characters": {
    "角色A": {
      "total_scenes": N,
      "dialogue_lines": N,
      "first_appearance": N,
      "role": "protagonist|antagonist|supporting",
      "motivation": "动机"
    }
  }
}

剧本内容：
{SCRIPT_CONTENT}
```

## Prompt 2: 五维分析

基于结构化JSON进行五维分析。

```
你是一个专业的短剧质量分析师。请基于以下结构化剧本数据，进行五维量化分析。

## 分析维度

### 1. 叙事结构（20分）
- 情节点密度 = 标记为plot_point的场景数 / 总场景数
- 三幕式吻合度 = 铺垫段(前25%)冲突均值 vs 冲突段(25-75%) vs 高潮段(后25%)
- 节奏变化 = 相邻场景conflict_level的标准差

### 2. 情感弧线（20分）
- 情绪波动范围 = emotion_words覆盖的情绪类别数 / 8
- 转场频率 = emotion_words显著变化的次数 / 总时长(分钟)
- 回归正向 = 结尾场景是否为正向情绪或强悬念

### 3. Hook强度（20分）
- 3秒Hook = 第1场景的conflict_level × 1.5 + 悬念值(0-5)
- 章节Hook = 每幕结尾是否有悬念
- 首次信息冲击 = 前10秒是否抛出核心矛盾

### 4. 角色网络（20分）
- 主角辨识度 = 主角出场频率和对话量
- 对立关系 = 主角与对手共场景数及冲突强度
- 角色功能 = 每个角色的叙事贡献度

### 5. 完播率预测（20分）
- 疲劳曲线 = 基于冲突密度计算注意力衰减
- 信息密度 = 每分钟新信息点数（3-5为最佳）
- 结尾留白 = 结尾悬念或情绪余韵强度

请输出：
1. 每个维度的具体得分和计算依据
2. 发现的具体问题（引用场景编号）
3. 场景级别的优化建议
4. 匹配最接近的剧本模式标签

结构化剧本数据：
{STRUCTURED_DATA}
```

## Prompt 3: 对比分析

```
你是一个短剧数据分析师。请对比以下两个剧本的五维分析数据，找出差异和规律。

输出格式：
1. 对比矩阵（每个维度的得分差）
2. 爆款剧本的结构优势（具体到场景级别）
3. 非爆款剧本的结构缺陷（具体到场景级别）
4. 可量化的改进建议

剧本A数据：
{DATA_A}

剧本B数据：
{DATA_B}
```

## Prompt 4: 快速Hook评估

```
快速评估以下开场场景的Hook强度（0-10分）。

评分标准：
- 10分：开场即高强度冲突（动作、暴力、重大反转）
- 8分：开场有明确矛盾和情绪张力
- 5分：开场有悬念但冲突不强
- 3分：开场有角色出场但无冲突
- 1分：开场缓慢，纯铺垫

同时回答：
1. 前3秒观众能获得什么信息？
2. 3秒后观众最大的疑问是什么？
3. 如何改进到8分以上？

开场场景：
{OPENING_SCENE}
```
