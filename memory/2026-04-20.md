### DepthFlow 安装与测试 ⭐
- 用户澄清要的是**图片→动态视频的空间感效果**，不是静态滤镜
- **DepthFlow** (GitHub: BrokenSource/DepthFlow) — 开源 GLSL shader 2.5D 引擎
- **安装在 Windows 端**（RTX 3060 Ti 8GB）：`C:\Python311\Scripts\depthflow.exe`
  - Python 3.11（Anaconda 3.9 太旧，numpy-quaternion 需要 3.10+）
  - `pip install depthflow` → v0.9.1
- **硬件**：RTX 3060 Ti（8GB VRAM），不是 RTX 4070，已纠正 TOOLS.md/记忆
- **性能**：1344x768@60fps，每个3秒视频约4秒生成（GLSL shader实时渲染）
- **深度估算器**：内置 DepthAnything V1/V2、DepthPro、ZoeDepth、Marigold（无需手动深度图）
- **6种动画预设**：horizontal, vertical, zoom, dolly, circle, orbital
- **3种后处理**：blur(DOF), vignette, lens(distortion)
- **CLI 语法**：`depthflow input -i IMAGE {animation} h264 main -t 3 -w 1344 -h 768 -o OUTPUT.mp4`
- **注意**：SSH 会话中 NVENC 不可用（无 GPU 访问），用 CPU h264 编码
- 生成了 12 个效果视频并发到群组
