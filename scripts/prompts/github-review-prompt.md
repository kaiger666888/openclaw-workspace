# GitHub 代码审查 Prompt

## 任务目标

对 umlVisionAgent 仓库的最新提交进行代码审查，生成中文审查报告。

## 执行步骤

### Step 1: 运行审查脚本
```bash
bash /home/kai/.openclaw/workspace/scripts/github-review.sh
```

### Step 2: 检查结果
- 如果脚本输出"无新提交"或"无需审查"，**跳过此任务**
- 如果有提交内容，继续 Step 3

### Step 3: 生成审查报告

将脚本输出整理为中文审查报告：

```markdown
> 代码审查：[日期] — [提交数量] 个提交

## 📋 审查概览
- 审查分支：main
- 提交数量：X 个
- 涉及文件：X 个

## 🔍 提交详情
### 1. [commit hash 前7位] [提交信息]
- **文件**：修改了哪些文件
- **变更类型**：新功能/修复/重构/文档
- **代码质量**：✅ 良好 / ⚠️ 有建议 / ❌ 有问题
- **审查意见**：具体建议

## 📊 总结
- 总体评价
- 需要关注的问题（如有）
- 改进建议
```

## 质量标准

- 审查意见要具体，不能只说"代码质量好"
- 发现的问题要给出修复建议
- 如果代码质量好，也要说明为什么好
- 审查报告写入 Notion 代码审查子页面

## 注意事项

- 这个任务**不搜索外部信息**，只审查代码
- 审查重点是代码质量，不是功能评价
- 如果没有新提交，直接跳过，不创建页面
