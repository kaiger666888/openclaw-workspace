## kais-archi 架构图优化 (Research_Vision 群, topic:415)

### 奥卡姆剃刀：图表类型精简
- **决策**：从 4 种图（管线/调用/时序/分层）精简为 3 种：流程图 + 依赖图 + 时序图
- **分层图砍掉**：信息已被依赖图的 subgraph 覆盖
- **时序图条件生成**：有多方交互时才生成，否则自动跳过
- **combined 图砍掉**：与 pipeline 冗余（去重逻辑会移除）

### Notion 页面链接问题修复
- **问题**：API 创建的子页面 URL 用户无法打开（"找不到此页面"）
- **根因**：Notion 页面 URL 中 UUID 部分不带连字符，且页面嵌套在子页面下不易找到
- **解决**：确认 API 返回的 URL 格式正确，用户通过导航到父页面找到子页面

### 图表宽度控制
- **问题**：layer-map 生态全景图过宽（专业能力层 38 节点横排）
- **方案**：每个 subgraph 最多 5 个节点（COLS=5），超过自动拆分为 ①②③...子图
- **依赖图同样优化**：MAX_NODES_PER_SUB 从 12 降为 6
- **mermaid-compressor**：splitBySubgraph 严格按 maxLen 拆分

### Notion mermaid 大图写入
- **问题**：Notion API rich_text 2000 字符限制导致大图写入失败
- **方案1**：appendCodeBlock 超过 1500 字符时用 --children-file JSON 格式写入
- **方案2**：compressor 对超大图自动按 subgraph 拆分（splitBySubgraph），每个 part ≤ 1900 字符
- **方案3**：flattenToEdges 保留 style/linkStyle 行（不丢弃样式）
