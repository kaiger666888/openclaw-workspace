## 通用采集模式

所有平台统一使用 snapshot 解析，不依赖 CSS 选择器：

```
browser snapshot → 提取文本 → 正则匹配数字 → 构造 JSON
```

数字格式处理：
- 中文数字转换：万 → ×10000，亿 → ×100000000
- 带逗号数字：移除逗号
- 百分比：移除 % 转为浮点
