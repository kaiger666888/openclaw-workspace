# 创业失败经验教训 Prompt

## 任务目标

每日推送创业公司的深度失败案例分析，提取可复用的教训，涵盖不同行业和失败类型。

## 搜索方向

- 创业公司 Postmortem（自述失败原因）
- CB Insights 失败原因研究
- 创始人访谈/反思文章
- 行业特定失败案例（SaaS、消费、金融科技等）
- 估值泡沫、烧钱过快等经典失败模式

## 搜索关键词

```
startup postmortem why we failed
startup failure case study 2026
创业失败复盘 经验教训
company shutdown reasons
```

## 内容结构

```markdown
> 今日失败案例：[公司名] — [失败类型一句话]

## 📋 案例概况
- **公司**：名称、行业、成立时间
- **来源**：[来源名](URL)
- **融资金额**：如已知
- **存续时间**：X 年 X 月

## 💀 失败原因分析
### 直接原因
- 导致倒闭的导火索

### 根本原因
- 深层问题（产品、市场、团队、资金等）

### 关键决策失误
- 哪些决策可以避免？（用 20/20 事后视角）

## 📊 数据洞察
- 融资/烧钱/增长等关键数据（如有）
- 失败时间线

## 🧠 核心教训（3 条）
1. **教训标题**：具体说明
   - 如何避免：如果你是创始人，该怎么做

## 🔗 延伸阅读
- 相关文章/数据来源链接
```

## 质量标准

- 案例必须有真实来源（创始人自述优先）
- 失败原因要分层次分析，不能只说"缺钱"
- "核心教训"要具体到可执行的级别
- 数据要有来源，不能编造
- 与 failure-lessons 区分：这个更侧重创业公司层面

## 搜索限制

- web_search: ≤ 2 次
- web_fetch: ≤ 3 次
