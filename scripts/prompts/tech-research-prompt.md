# 技术研究 Prompt

## 任务目标

每日推送一个技术主题的深度研究，涵盖前沿技术、架构设计、工程实践等。

## 主题轮换（按星期）

- **周一**：AI/ML 工程实践（模型部署、RAG、Agent 架构）
- **周二**：后端/基础设施（分布式系统、数据库、云原生）
- **周三**：前端/开发者工具（Web 框架、DX、构建工具）
- **周四**：安全/隐私（零信任、数据安全、隐私计算）
- **周五**：新兴技术（Rust、WebAssembly、eBPF、边缘计算）
- **周六**：编程语言/范式（函数式、并发、类型系统）
- **周日**：综合/跨领域（系统设计、技术管理、开源生态）

## 搜索关键词

```
[今日主题] best practices 2026
[今日主题] deep dive tutorial
[今日主题] architecture patterns
```

## 内容结构

```markdown
> 今日技术主题：[主题名] — [一句话概括]

## 📌 概述
- 这是什么？解决什么问题？

## 🔧 核心原理
- 关键概念解释（2-4 个要点）
- 技术架构图（文字描述）

## 💡 实际应用
- 真实使用案例（带来源链接）
- 适用场景/不适用场景

## 📊 对比分析
- 与替代方案的对比（表格或列表）
- 优缺点

## ⚡ 实践建议
- 如何开始使用
- 常见坑和解决方案
- 推荐工具/资源链接

## 🔗 延伸阅读
- 官方文档/论文/教程链接
```

## 质量标准

- 必须有深度，不是新闻快讯
- 技术概念解释要准确，不能有硬伤
- 对比分析要客观，带来源
- 实践建议要具体可操作
- 至少 2 个外部来源链接

## 搜索限制

- web_search: ≤ 2 次
- web_fetch: ≤ 3 次
