# 失败经验总结 Prompt

## 任务目标

每日推送真实的企业/项目失败案例分析，提取可复用的教训，避免重蹈覆辙。

## 搜索方向

- 知名公司失败案例（科技/互联网/创业）
- 产品失败案例（Google, Meta, Apple 等失败产品）
- 创业公司倒闭分析
- 项目管理失败经验
- 技术决策失误案例

## 搜索关键词

```
startup failure analysis 2026
why companies fail case study
product failure examples tech
project management lessons learned
创业失败案例分析
```

## 内容结构

```markdown
> 今日失败教训：[一句话总结]

## 📉 案例 1：[公司/项目名]
- **来源**：[来源名](URL)
- **背景**：行业/规模/时间
- **失败原因**（逐条分析）
- **核心教训**（2-3 条可执行的建议）
- **如何避免**：如果你面临类似情况该怎么办

## 📉 案例 2：[公司/项目名]
- （同上结构）

## 🧠 共性规律
- 从今日案例中提炼出的通用规律

## ⚡ 行动清单
- 读者可以立即采取的预防措施
```

## 质量标准

- 案例必须有真实来源（新闻报道、Postmortem、创始人访谈）
- 失败原因分析要深入，不能只说"市场不好"
- "核心教训"要具体可执行，不是空话
- 避免重复近期已推送过的案例

## 搜索限制

- web_search: ≤ 2 次
- web_fetch: ≤ 3 次
