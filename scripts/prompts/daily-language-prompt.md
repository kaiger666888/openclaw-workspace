# 每日英语德语 Prompt

## 任务目标

每日推送英语和德语学习内容，包含每日一句、语法要点、重点词汇。

## ⚠️ 去重要求（强制执行）

生成每日一句之前，必须先检查去重：

```bash
# 检查是否重复（返回 0=不重复）
python3 /home/kai/.openclaw/workspace/scripts/lib/dedupe-validator.py \
  english-german check --quote "待选格言" --author "作者名"
```

如果返回 1（重复），必须换一句。生成成功后：

```bash
# 记录到数据库
python3 /home/kai/.openclaw/workspace/scripts/lib/dedupe-validator.py \
  english-german add --quote "格言" --author "作者" --source "来源" --page-id "PAGE_ID"
```

## 每日一句选择原则

- 优先选择有思想深度的格言（而非日常口语）
- 来源多样化：哲学家、作家、科学家、企业家
- 避免连续两天同一作者

## 内容结构

```markdown
> 今日语言学习

## 🇬🇧 英语

### 💬 每日一句
> "Quote text"
> — Author, Source

**翻译**：中文翻译
**语法要点**：这句话中的关键语法结构
**词汇**：生词解释（3-5 个）
**用法提示**：如何在日常中使用类似表达

## 🇩🇪 德语

### 💬 每日一句
> "Zitat"
> — Autor

**翻译**：中文翻译
**语法要点**：关键语法（变格、时态、语序等）
**词汇**：生词解释（3-5 个）
**动词变位**：相关动词的现在时/过去时变位表

## 📚 学习小贴士
- 今日的一个语言学习建议
```

## 质量标准

- 每日一句必须经过去重检查
- 语法解释要准确（尤其是德语）
- 翻译要自然流畅
- 词汇选择要有实用性
- 格言要有思想价值

## 搜索限制

- web_search: ≤ 1 次（找格言时）
- 优先使用已有知识生成
- 德语内容要特别谨慎，确保准确性

## 块数标准

- ✅ ≥ 20 块：合格（语言学习内容不需要 50 块）
