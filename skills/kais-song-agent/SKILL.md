# kais-song-agent — AI 歌曲创作全流程 Agent

基于 ACE-Step 1.5 引擎的智能歌曲创作助手。专注创作技巧和艺术质量，技术执行交给 Kais Hub 管线。

## 创作哲学

**AI 是乐器，不是创作者。** 本 skill 的角色是音乐制作人——理解用户意图、设计创作方案、把控艺术质量。ACE-Step 1.5 是执行引擎，通过 Kais Hub (`kais-gold-team`) 的 Docker 管线调度。

## 核心流程

```
用户意图 → 创意构思 → 歌词创作 → 编曲设计 → 提交引擎 → 审核交付
           ①          ②          ③          ④          ⑤
```

### ① 创意构思

理解用户的创作意图，帮助明确：

**必须确认的信息：**
- **情感基调**：快乐/悲伤/激昂/温柔/迷茫/坚定/怀旧…（可用多个，标注主次）
- **音乐风格**：流行/摇滚/民谣/电子/R&B/嘻哈/古典/国风/爵士/乡村…
- **目标听众**：自己/朋友/公开发布/特定场景（婚礼/毕业/纪念…）
- **语言**：中文/英文/日文/韩文（影响人声语言）

**可选信息（有则更好）：**
- 参考歌曲（"类似 XXX 的风格"）
- 主题/故事线（"关于远方的思念"）
- 时长期望（默认 30s，最长可 600s）
- 人声类型偏好（男声/女声/合唱）

**输出**：结构化创意简报（Creative Brief）

```markdown
## 创意简报
- 情感基调：[主]XX [次]XX
- 音乐风格：XX
- 语言：XX
- 主题：XX
- 参考氛围：XX
- 时长：XXs
```

用户确认后进入歌词创作。

### ② 歌词创作

<!-- FREEDOM:high -->

这是最核心的创作环节。遵循以下原则：

#### 歌词结构设计

| 结构 | 适用场景 | 时长参考 |
|------|---------|---------|
| 主歌-副歌 (AB) | 短曲、民谣 | 30-60s |
| 主歌-副歌-主歌-副歌 (ABAB) | 流行标准 | 60-120s |
| 主歌-预副歌-副歌-桥段-副歌 (ABCAB) | 完整流行歌 | 120-240s |
| 前奏-主歌-副歌-间奏-主歌-副歌-尾奏 | 民谣/摇滚 | 180-300s |

#### 歌词创作技巧

**1. 押韵策略**
- **偶数行押韵**（最常见）：第2、4、6行句尾押韵
- **ABAB 交叉韵**：第2、4行押韵，第1、3行押另一韵
- **一韵到底**：整段/整首保持同一韵脚（适合说唱、民谣）
- **换韵**：每个段落换韵（适合流行、摇滚）
- **注意**：中文押韵看韵母，英文押韵看元音+辅音尾

**2. 意象与修辞**
- 用具体意象代替抽象情感（❌"我很想你" → ✅"咖啡凉了第二杯"）
- 通感手法：用一种感官描写另一种（"她的笑声是薄荷色"）
- 排比递进：情感层层叠加（"走过…经过…路过…"）
- 对比反差：制造情感张力（"最热闹的城市，最安静的角落"）

**3. 节奏与韵律**
- 每行字数尽量一致或递变（控制音节数）
- 长短句交替制造呼吸感
- 副歌歌词要"上口"——重复是关键
- 预留呼吸口（人声需要换气时间）

**4. 情感弧线**
- 开头：铺垫氛围（写景/叙事/提问）
- 发展：推进情感（细节/转折/冲突）
- 高潮：情感爆发（副歌/金句/重复）
- 收束：余韵或转折（留白/反转/呼应开头）

**5. ACE-Step 歌词格式要求**

ACE-Step 使用 `[Section]` 标签标记歌曲结构：

```
[Intro]
(前奏，可留空或写氛围描述)

[Verse 1]
主歌第一段歌词

[Pre-Chorus]
预副歌（可选）

[Chorus]
副歌歌词

[Verse 2]
主歌第二段歌词

[Bridge]
桥段（可选）

[Chorus]
副歌歌词

[Outro]
尾奏（可留空）
```

**关键注意：**
- 歌词行间用空行分隔
- `[Chorus]` 段落可以重复（模型会理解为副歌重复）
- 歌词质量直接影响人声唱出的效果——越自然的歌词，唱出来越流畅
- 避免过于书面化/文言文，口语化表达效果更好

#### 歌词质量自检

生成歌词后，用以下清单自检：

- [ ] 情感基调与创意简报一致
- [ ] 押韵自然，不生硬
- [ ] 意象具体，无空洞表达
- [ ] 节奏感好，朗读顺畅
- [ ] 副歌"上口"，有记忆点
- [ ] 结构标签完整（`[Verse]`/`[Chorus]`等）
- [ ] 总歌词量适合目标时长（30s ≈ 4-6 行，60s ≈ 8-12 行）

### ③ 编曲参数设计

<!-- FREEDOM:low -->

将创意简报转化为 ACE-Step 引擎参数。这是技术环节，必须精确。

#### 参数映射

将创意简报映射为 ACE-Step 参数（`prompt`、`lyrics`、`vocal_language`、`bpm`、`duration`、`model`、`inference_steps`）。

**详细参数表和 Prompt 示例库** → 见 `references/acestep-params.md`

**Prompt 写作公式**：`[音乐风格], [人声描述], [主要乐器], [氛围/情感], [节奏特征]`

**关键原则**：英文写、具体优于抽象、3-5 个描述足够、声明人声特征和氛围

#### 模型选择建议

| 需求 | 模型 | 步数 | 质量/速度 |
|------|------|------|----------|
| 快速试听/迭代 | `acestep-v15-turbo` | 8 | ⚡快 / 质量很高 |
| 最终交付 | `acestep-v15-sft` | 50 | 🐢慢 / 质量最高 |
| 风格探索 | `acestep-v15-base` | 50 | 🐢慢 / 风格多样 |

### ④ 提交引擎

<!-- FREEDOM:low -->

通过 Kais Hub 管线提交任务。引擎接口在 `kais-gold-team` 仓库的 `kais-hub` 中。

**任务类型**：`music_generation`

**提交方式**：通过 Kais Hub 的 Telegram 命令 `/music` 或 `/compose` 提交，或直接调用控制节点 API。

**参数构建示例**：见 `references/acestep-params.md` 完整参数列表

**迭代策略**：
1. **第一版**：用 turbo 模型快速生成（~15-30s），验证方向
2. **调整**：根据结果调整 prompt/歌词/参数
3. **终版**：满意后用 sft 模型生成高质量版本（~1-3min）

### ⑤ 审核交付

收到生成结果后，从艺术角度审核：

**审核维度：**
- 🎤 **人声质量**：吐字清晰度、情感表达、音准
- 🎵 **旋律**：是否上口、是否有记忆点、旋律走向是否合理
- 🎹 **编曲**：乐器搭配是否协调、层次感、动态变化
- 📐 **结构**：段落数量、过渡是否自然、时长是否合适
- 🎭 **氛围**：整体氛围是否符合创意简报

**不满意时的调整策略：**

| 问题 | 调整方向 |
|------|---------|
| 人声不清晰 | 检查歌词是否过于书面化；调低 BPM |
| 风格不对 | 重写 prompt，更具体的风格描述 |
| 旋律平淡 | 在 prompt 中强调 "catchy melody" / "memorable hook" |
| 编曲单调 | 在 prompt 中增加乐器描述 |
| 太短/太长 | 调整 `duration` 参数 |
| 情感不对 | 调整歌词内容 + prompt 情感描述 |

**交付物：**
- MP3 音频文件
- 创作说明（使用的参数、迭代过程）
- 如有参考歌曲，附对比说明

## 特殊模式

### 翻唱模式 (Cover)

用户提供源音频 + 目标风格描述，生成翻唱版本。

```
用户：把这首歌翻唱成爵士风格
→ 提取原曲旋律和结构
→ 重新编曲 + 新人声
→ 交付翻唱版本
```

### 混音模式 (Remix)

用户提供源音频 + 目标风格，风格迁移。

### Simple 模式

用户只给一句话描述，模型自动生成歌词+旋律+编曲。适合快速探索。

```
用户：帮我做一首关于春天的轻快歌曲
→ 自动生成完整歌曲
→ 用户可以在此基础上调整
```

## 创作技巧速查

### 常见歌曲结构模板

**流行歌 (Pop Song)**
```
[Intro] → [Verse 1] → [Pre-Chorus] → [Chorus] → 
[Verse 2] → [Pre-Chorus] → [Chorus] → 
[Bridge] → [Chorus] → [Outro]
```

**民谣 (Folk)**
```
[Intro] → [Verse 1] → [Verse 2] → [Chorus] → 
[Verse 3] → [Chorus] → [Outro]
```

**电子舞曲 (EDM)**
```
[Intro] → [Build-up] → [Drop] → [Verse] → 
[Build-up] → [Drop] → [Outro]
```

### 情感-风格映射参考

| 情感 | 推荐风格 | 推荐乐器 | BPM 范围 |
|------|---------|---------|---------|
| 浪漫 | 流行/R&B | 钢琴、弦乐 | 60-90 |
| 激昂 | 摇滚/电子 | 电吉他、合成器 | 120-140 |
| 忧伤 | 民谣/流行 | 木吉他、钢琴 | 70-90 |
| 欢快 | 流行/放克 | 吉他、贝斯、鼓 | 100-130 |
| 神秘 | 电子/氛围 | 合成器、采样 | 80-110 |
| 温暖 | 民谣/爵士 | 木吉他、萨克斯 | 70-100 |
| 力量 | 摇滚/史诗 | 电吉他、管弦乐 | 100-140 |
| 怀旧 | 国风/民谣 | 古筝、笛子、吉他 | 60-90 |

### 歌词灵感触发

当用户说"随便写一首"或没有明确主题时，从以下方向引导：

1. **时间**：清晨/深夜/四季/某个年龄
2. **空间**：城市/故乡/远方/某个角落
3. **关系**：亲情/友情/爱情/孤独
4. **成长**：梦想/挫折/蜕变/释然
5. **日常**：一杯咖啡/一扇窗/一次偶遇

## 限制与注意

- ACE-Step 1.5 在 8GB VRAM 上运行，长音频（>120s）生成较慢
- 人声语言支持中/英/日/韩，其他语言效果不佳
- 歌词质量是最终效果的最大变量，值得花时间打磨
- 每次生成有随机性（seed），同一参数可能产生不同结果
- turbo 模型 8 步已足够好，不必迷信 sft 50 步
