# kais-first-principle

用第一性原理拆解问题，从本质出发重建推理链。

## 概述

第一性原理（First Principles Thinking）是一种从最基本的事实和物理定律出发、不依赖类比和经验进行推理的思维方法。源自亚里士多德，被 Elon Musk 推广为创新的核心方法论。

本 skill 提供结构化的第一性原理分析框架，可用于：
- 深度问题分析（独立使用）
- 作为子流程被其他 skill 调用（元技能模式）

## 两种使用模式

### 模式 A：独立调用

用户直接触发，完整执行五步框架，输出分析报告。

### 模式 B：被其他 skill 调用

其他 skill 在关键决策点嵌入第一性原理分析步骤。调用方式：

```
在执行 [具体任务] 前，先用第一性原理框架分析：
1. 问题的本质是什么？
2. 哪些假设需要验证？
3. 从基本事实出发的最优解是什么？
分析完成后继续执行原任务。
```

## 五步框架

<!-- FREEDOM:high -->

### 步骤 1：界定问题（Define）

**目标**：用一句话精确描述要解决的问题。

方法：
- 剥离形容词和修饰语，只保留核心名词和动词
- 问"这到底是在解决什么？"
- 如果能用 10 岁小孩听懂的话复述，说明界定清楚了

输出格式：
```
问题陈述：[一句话]
问题类型：[技术决策 / 商业策略 / 个人选择 / 系统设计 / 创新突破]
约束条件：[已知不可变的限制]
期望结果：[理想状态描述]
```

### 步骤 2：剥离假设（Decompose）

**目标**：识别并质疑所有隐含假设。

对问题相关的每个"常识"问：
- 这是事实还是观点？
- 这个结论的依据是什么？
- 如果这个假设不成立，结论还成立吗？

**三张清单：**
- 🔵 **确认事实**：有数据/物理定律支撑，不可推翻
- 🟡 **待验证假设**：看似合理但需要证据
- 🔴 **无效假设**：基于类比或传统经验，可能误导

### 步骤 3：回归公理（Axiomatize）

**目标**：从确认事实中提取不可再分的基本公理。

方法：
- 对每个确认事实追问"为什么"，连续追问直到触底（类似 5 Whys）
- 底层答案就是公理
- 公理标准：① 有物理/数学/逻辑支撑 ② 无法再分解 ③ 不依赖其他假设

输出格式：
```
公理 1：[基本事实] → 来源：[物理定律/数学原理/实验数据/逻辑必然]
公理 2：[基本事实] → 来源：[...]
公理 3：[基本事实] → 来源：[...]
```

### 步骤 4：重建推理（Reconstruct）

**目标**：仅从公理出发，重新推导解决方案。

方法：
- 忘掉现有方案，只看公理
- 从公理出发，用逻辑推导可能的路径
- 每条路径都要可回溯到某个公理
- 鼓励"荒谬"的想法——如果逻辑正确，再荒谬也值得考虑

**评估每个方案：**
- 与公理的一致性（满分 5）
- 可行性（满分 5）
- 创新度（满分 5）

### 步骤 5：输出洞察（Synthesize）

**目标**：将推理过程凝练为可行动的洞察。

输出格式：
```
## 第一性原理分析报告

### 问题本质
[一句话总结]

### 关键公理
1. [公理 1]
2. [公理 2]
3. [公理 3]

### 推翻的假设
- ❌ [被推翻的假设 1] → 实际情况：[...]
- ❌ [被推翻的假设 2] → 实际情况：[...]

### 从公理推导的方案
| 方案 | 公理基础 | 一致性 | 可行性 | 创新度 |
|------|---------|--------|--------|--------|
| A    | ...     | 5/5    | 4/5    | 5/5    |
| B    | ...     | 4/5    | 5/5    | 3/5    |

### 核心洞察
[最反直觉但逻辑最严密的发现]

### 行动建议
1. [立即可以做的]
2. [中期可以探索的]
3. [长期值得研究的]
```

## 经典案例参考

### SpaceX 火箭成本
- **问题**：火箭太贵，无法实现火星殖民
- **假设**：火箭就是贵的，从俄罗斯买是唯一选择
- **公理**：火箭由铝合金、钛、碳纤维、铜等原材料组成，原材料成本仅占售价的 ~2%
- **推导**：既然材料这么便宜，贵的不是材料而是制造流程。自己造火箭，重新设计制造流程。
- **结果**：Falcon 9 成本降低 ~90%

### Tesla 电池成本
- **问题**：电池组太贵（$600/kWh），电动车无法普及
- **假设**：电池就是贵的，这是行业共识
- **公理**：电池的材料成分（钴、镍、铝、碳、聚合物）在伦敦金属交易所的价格约 $80/kWh
- **推导**：材料成本远低于成品价格。通过创新电池设计和生产工艺，可以逼近材料成本。
- **结果**：自建电池工厂，成本大幅下降

### 本 skill 的设计
- **问题**：需要一个通用的深度思维工具
- **假设**：需要复杂的 AI 推理系统
- **公理**：第一性原理的本质是"追问到底 + 从公理重建"，这是一个确定性流程
- **推导**：用结构化的五步框架就能实现，不需要外部工具，纯文本指导即可

## 注意事项

- 第一性原理 ≠ 否定一切经验，经验在"待验证假设"阶段有参考价值
- 不要在每件小事上都用第一性原理，它适合**重要决策**和**创新突破**
- 公理提取是关键步骤——如果公理错了，后面的推导都白费
- 被其他 skill 调用时，保持简洁：只输出步骤 1-4 的精简版，不要完整报告
