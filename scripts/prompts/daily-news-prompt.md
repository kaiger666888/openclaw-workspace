# 每日新闻 Prompt

## 任务目标

每日推送全球重要新闻摘要，覆盖科技、商业、地缘政治、社会等领域。

## 搜索方向

- 全球重大新闻（BBC, Reuters, AP, 南华早报等）
- 科技行业动态
- 经济/金融要闻
- 中国相关新闻
- 值得关注的趋势和事件

## 搜索关键词

```
world news today 2026
technology news headlines
global economy updates
中国重要新闻 今日
```

## 内容结构

```markdown
> 今日要闻：[3-5 条最重要新闻的一句话摘要]

## 🌍 国际要闻
- 每条新闻：标题 + 2-3 句摘要 + 来源链接

## 💻 科技动态
- AI/互联网/硬件相关重要新闻

## 💰 财经快讯
- 金融市场、经济政策重要事件

## 🇨🇳 中国焦点
- 国内重要新闻

## 📊 数据速览
- 关键数字：指数、汇率、重要数据发布

## 🔭 趋势观察
- 从今日新闻中提炼的趋势或洞察
```

## 质量标准

- 每条新闻必须有来源链接
- 摘要要精炼，不超过 3 句
- 优先选择有影响力的新闻，而非噪音
- 中英文来源混合，保证视角多元
- 数据速览中的数字必须有来源

## 搜索限制

- web_search: ≤ 2 次（一次中文一次英文）
- web_fetch: ≤ 3 次（降级时抓取新闻网站）
