# 分析框架参考

## 认知偏差清单

分析 Kai 的行为时，关注以下常见认知偏差是否出现：

| 偏差 | 描述 | 识别信号 |
|------|------|----------|
| 确认偏差 | 只关注支持已有信念的信息 | 反复选择相同方案，忽视反面证据 |
| 沉没成本谬误 | 因已投入而继续错误方向 | "都做了这么多了" 类表述 |
| 锚定效应 | 过度依赖最先获得的信息 | 首次决策影响后续所有判断 |
| 计划谬误 | 低估时间/成本，高估能力 | 任务频繁延期 |
| 邓宁-克鲁格效应 | 能力低时高估自己 | 跳过基础直接做复杂事 |
| 幸存者偏差 | 只看到成功案例 | 分析失败时忽略同类失败 |
| 损失厌恶 | 失去的痛苦 > 获得的快乐 | 回避有风险但有收益的选择 |
| 现状偏差 | 偏好维持现状 | 长期不改变低效流程 |

## 决策风格模型

### MBTI 决策维度
- **T/F**（思考/情感）：逻辑优先 vs 价值优先
- **J/P**（判断/感知）：计划型 vs 灵活型
- **S/N**（感觉/直觉）：细节导向 vs 模式识别
- **I/E**（内向/外向）：内部思考 vs 外部讨论

### CTI 决策风格
- **Maximizer**：追求最优解，可能耗时
- **Satisficer**：找到"够好"的方案就执行
- **Compromiser**：在两者之间平衡

## 行为模式识别

### 习惯循环 (Cue → Routine → Reward)
```
触发线索 → 自动行为 → 奖励反馈
```
分析时关注：
1. 什么情境触发特定行为？
2. 行为的固定模式是什么？
3. 什么奖励维持了这个循环？

### 重复错误模式
- 同类错误在不同场景出现
- "我知道但做不到"的循环
- 解决方案有效但不去执行

## 成长评估

### Dreyfus 技能习得模型
1. **新手** — 需要明确规则和指导
2. **高级新手** — 开始识别模式
3. **胜任者** — 能独立处理常规问题
4. **精通者** — 能从全局视角决策
5. **专家** — 直觉式决策，难以言传

### 学习曲线信号
- 从"记录规则"到"内化习惯"
- 从"模仿"到"创新"
- 从"求助"到"自主解决"
- 从"宽泛兴趣"到"深度聚焦"
