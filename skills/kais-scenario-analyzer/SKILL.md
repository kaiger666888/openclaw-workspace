# kais-scenario-analyzer

剧本叙事结构量化分析系统。将直觉叙事转化为可量化的数据指标，为AIGC短剧工业化生产提供品控前置能力。

## 核心价值

- **品控前置**：拍之前发现问题，比拍完再改成本低10倍
- **量化直觉**：把"感觉不对"转化为具体指标和改进建议
- **对标验证**：通过爆款/非爆款案例对比，建立可量化的质量标准

## 输入要求

接受以下格式的剧本输入：

1. **结构化剧本JSON**（推荐）：`kais-scenario-writer` 或 `kais-shooting-script` 的输出
2. **纯文本剧本**：标准剧本格式（场景标题 + 对话 + 动作描写）
3. **故事大纲**：简化版分析，仅覆盖结构层

## 分析流程

### Phase 1: 剧本解析

从剧本中提取结构化数据：

```json
{
  "scenes": [
    {
      "index": 1,
      "location": "办公室",
      "time": "白天",
      "characters": ["张三", "李四"],
      "dialogue_count": 5,
      "action_density": 0.3,
      "emotion_words": ["愤怒", "失望"],
      "conflict_level": 8,
      "duration_estimate": 15
    }
  ],
  "characters": {
    "张三": { "scenes": [1,2,3,5], "dialogue_lines": 12, "role": "protagonist" },
    "李四": { "scenes": [1,3,4], "dialogue_lines": 8, "role": "antagonist" }
  },
  "total_duration_estimate": 120
}
```

**解析方法**：
- 如果输入是结构化JSON，直接提取
- 如果是纯文本，用 LLM 按 prompt 模板解析为上述结构

### Phase 2: 五维分析

<!-- FREEDOM:low -->
**必须按以下五个维度依次分析，每个维度输出标准化指标。**

#### 维度1：叙事结构（Structure Score, 20分）

| 指标 | 计算方法 | 满分 |
|------|----------|------|
| 情节点密度 | 关键情节节点数 / 总场景数 | 8 |
| 三幕式吻合度 | 铺垫(25%)→冲突(50%)→高潮(25%) 的时间占比偏差 | 6 |
| 节奏变化 | 相邻场景冲突强度的标准差（变化越大越好） | 6 |

**情节点识别规则**：
- 激励事件（Inciting Incident）：第一个打破平衡的事件
- 中点转折（Midpoint）：信息反转或关系变化
- 高潮（Climax）：冲突强度最高的场景
- 结局（Resolution）：冲突解决或新冲突建立

**扣分项**：
- 连续3个以上场景冲突强度 < 3（拖沓）→ -3/处
- 高潮出现在最后10%之前（过早泄气）→ -4
- 无明确的激励事件 → -5

#### 维度2：情感弧线（Emotion Score, 20分）

| 指标 | 计算方法 | 满分 |
|------|----------|------|
| 情绪波动范围 | 全剧情绪极性跨度（-1到1） | 7 |
| 转场频率 | 情绪显著变化的次数（短剧要求≥5次/分钟） | 7 |
| 回归正向 | 结局情绪是否回归正向（或留下有力悬念） | 6 |

**情绪分类**：愤怒、恐惧、悲伤、厌恶、惊讶、期待、信任、喜悦（Plutchik八维）

**扣分项**：
- 连续场景情绪无变化（情绪平坦）→ -3/处
- 开场情绪为负面且无回升（压抑开头）→ -4
- 结局情绪无着落（烂尾感）→ -3

#### 维度3：Hook强度（Hook Score, 20分）

| 指标 | 计算方法 | 满分 |
|------|----------|------|
| 3秒Hook | 开场场景的冲突强度 + 悬念值 | 10 |
| 章节Hook | 每幕/每段结尾的悬念设置 | 5 |
| 首次信息冲击 | 前10秒内是否抛出核心矛盾或反转 | 5 |

**3秒Hook评分标准**：
- 10分：开场即冲突（动作/悬念/反转）
- 7分：开场有情绪张力但缺冲突
- 4分：开场平铺直叙但有悬念暗示
- 1分：开场缓慢，无任何钩子

**短剧黄金法则**：前3秒必须让观众产生"然后呢？"的反应。

#### 维度4：角色网络（Character Score, 20分）

| 指标 | 计算方法 | 满分 |
|------|----------|------|
| 主角辨识度 | 主角出场频率/对话量占比 | 7 |
| 对立关系 | 主角vs对手的互动频率和冲突强度 | 7 |
| 角色功能 | 每个角色是否有明确叙事功能 | 6 |

**扣分项**：
- 无明确对手角色 → -5
- 角色超过5个且功能模糊 → -3
- 主角在关键场景缺席 → -4

#### 维度5：完播率预测（Engagement Score, 20分）

| 指标 | 计算方法 | 满分 |
|------|----------|------|
| 疲劳曲线 | 基于冲突密度的观众注意力衰减预测 | 8 |
| 信息密度 | 每分钟新信息量（过高或过低都扣分） | 6 |
| 结尾留白 | 结尾是否设置续集悬念或情绪余韵 | 6 |

**疲劳曲线计算**：
```
注意力(t) = 基础值 × e^(-衰减率×t) × 冲突增益(t)
```
- 衰减率：基于连续低冲突场景的累积时间
- 冲突增益：高冲突场景恢复注意力

**完播率预测等级**：
- A级（>80%预期）：结构紧凑，节奏强劲，结尾有力
- B级（60-80%）：整体良好，有1-2处可优化
- C级（40-60%）：存在明显拖沓或结构问题
- D级（<40%）：重大结构缺陷，建议重写

## 对比验证模式

**当用户要求对比分析时，必须执行以下流程。**

### 爆款 vs 非爆款对比

输入两个或多个剧本，生成对比矩阵：

```
📊 对比分析矩阵

指标          爆款均值    非爆款均值    当前剧本    差距
────────────────────────────────────────────────────
情节点密度    X.XX       X.XX         X.XX       ±X%
情绪转场频率  X.XX/min   X.XX/min     X.XX/min   ±X%
Hook强度      X.XX       X.XX         X.XX       ±X%
疲劳曲线斜率  X.XX       X.XX         X.XX       ±X%
完播率预测    XX%        XX%          XX%        ±X%
```

### 对标数据库

内置参考标准（基于短剧平台数据分析）：

**爆款剧本特征（Top 10%完播率）**：
- 情节点密度：≥0.4（每2.5个场景有1个关键情节点）
- 情绪转场频率：≥5次/分钟
- 3秒Hook得分：≥8
- 主角对话占比：40-60%
- 疲劳曲线衰减：≤15%（全剧注意力衰减不超过15%）

**非爆款剧本特征（Bottom 30%完播率）**：
- 情节点密度：<0.2
- 情绪转场频率：<2次/分钟
- 3秒Hook得分：<4
- 无明确对手角色
- 连续拖沓段≥30秒

## 与其他 Skill 的协作

| 上游 Skill | 输出 | 本 Skill 用途 |
|-----------|------|--------------|
| kais-scenario-writer | 剧本文件 | 完整分析 |
| kais-storyboard-designer | 分镜脚本 | 结构+Hook分析 |
| kais-shooting-script | 拍摄参数 | 节奏分析 |

| 下游 Skill | 输入 | 本 Skill 输出 |
|-----------|------|--------------|
| kais-movie-gate | 质量评估 | 结构维度评分 |
| kais-audience | 受众测试 | 预测数据 |

## 输出格式

1. **终端报告**：直接在对话中展示评分报告（默认）
2. **JSON数据**：`--format json` 输出结构化数据，供其他 skill 消费
3. **对比图表**：对比模式下生成文本图表

## 使用示例

```
用户: 分析这个剧本 /tmp/script.json
→ 执行完整五维分析，输出评分报告

用户: 对比分析 /tmp/hit-script.json 和 /tmp/miss-script.json
→ 执行对比分析，生成对比矩阵

用户: 这个剧本的Hook够强吗？ /tmp/script.json
→ 仅执行Hook维度分析（快速模式）
```

## 快速模式

用户只关心某个维度时，可指定单一维度分析：
- `--dimension structure` → 仅叙事结构
- `--dimension emotion` → 仅情感弧线
- `--dimension hook` → 仅Hook强度
- `--dimension character` → 仅角色网络
- `--dimension engagement` → 仅完播率预测
